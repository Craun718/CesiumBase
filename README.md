# Vue 3 + TypeScript + Vite

This template should help get you started developing with Vue 3 and TypeScript in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

## Styles

Tailwind CSS v4 is loaded by `@tailwindcss/vite`; its entry and shared theme tokens are in the global style block of `src/App.vue`. Tailwind utilities can be used directly in Vue templates.

Sass is available through Vite. Keep component styles in the component:

```vue
<style scoped lang="scss">
.example {
  .title {
    color: var(--text-primary);
  }
}
</style>
```

Styles that target DOM generated by deck.gl must use Vue's `:deep()` or `:global()` selectors. Avoid adding project-level CSS or Sass files unless a style is genuinely global and cannot live in `App.vue`.

## deck.gl

`src/components/DeckMap.vue` owns only the map container and layout. Deck instance creation, base-map layers, overlays, interaction, and cleanup live in `src/map/useDeckMap.ts`.
