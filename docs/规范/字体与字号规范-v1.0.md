# 字体与字号规范 v1.0

> 状态：v1.0 实施稿
> 适用范围：全站 Vue 组件、SCSS 与 `src/styles/global.css` 设计令牌
> 配套令牌：所有数值集中在 `src/styles/global.css` 的 Tailwind `@theme` 与 `:root` 段，本文件不另行维护数值常量。

## 1. 目标

当前全站使用 Tailwind v4 + 自定义 `@theme`，但字体与字号长期存在以下问题：

- 大量组件直接写 `font-size: 12px / 13px / 14px / 15px / 17px / 19px` 等硬编码值，绕开了全局令牌。
- 部分边界场景出现 `8px / 9px` 字号，可读性差、违反 WCAG。
- `--font-data` 早期存在自引用（`var(--font-data)`），导致任何使用该变量的节点没有等宽字体栈。
- 已定义的 `.text-display / .text-title / .text-subheading / .text-body / .text-label / .text-caption / .text-overline / .text-mono` 角色类几乎未被组件引用。

本规范要做三件事：

1. 把字号收敛到 8 档 `xxs–3xl`，并通过 `--text-display/title/subheading/body/label/caption/overline` 角色令牌指派唯一字号。
2. 把字体收敛到两条栈：界面字体 `--font-interface` 与等宽字体 `--font-mono`，并把历史别名 `--font-data` 永久指向 `--font-mono`。
3. 用 8 个角色类统一组件写法，所有新组件必须使用角色类，已存在组件按本规范迁移。

## 2. 设计原则

| 原则             | 做法                                                             | 反例                                 |
| ---------------- | ---------------------------------------------------------------- | ------------------------------------ |
| **基线可读**     | 正文 ≥ 13px，次要说明 ≥ 11px；11px 仅作为 caption 而非主信息载体 | 把关键告警数字放在 9px 角标里        |
| **梯度连贯**     | 同一行内字号差 ≤ 1 档；同一组件内字号差 ≤ 2 档                   | 标题 18px 直接跳到 11px 而无中间过渡 |
| **对比度优先**   | 暗色面板下，body/caption 必须 ≥ 4.5:1，overline/图标 ≥ 3:1       | `--text-muted` 用作主要操作色        |
| **节奏统一**     | 字号梯度与字重梯度共同决定视觉层级，而非依赖颜色或装饰           | 字号一致时仅靠 `--cyan` 区分层级     |
| **数字稳定**     | 表格、列表、KPI 数字统一开启 `tabular-nums` 并使用等宽字体       | 同一列中数字与文本混排导致宽度抖动   |
| **无障碍兜底**   | 字号 ≥ 13px、按钮命中区 ≥ 32px、焦点环清晰可见                   | 依赖 hover 提示关键信息、移除焦点环  |
| **字体仅作令牌** | 所有数值走 `var(--text-*)` / `var(--icon-*)` / `var(--font-*)`   | 直接 `font-size: 12px`、自定义字体栈 |

## 3. 字号梯度

仅保留以下 8 档，单位一律 `px`，写在 `src/styles/global.css` 的 `@theme` 块：

| 令牌          | 数值 | 角色映射                  | 最小可读场景                               |
| ------------- | ---- | ------------------------- | ------------------------------------------ |
| `--text-2xs`  | 10   | `--text-overline`         | 全大写英文短标签、徽章                     |
| `--text-xs`   | 11   | `--text-caption`          | 角注、坐标读数；不得承载主信息             |
| `--text-sm`   | 12   | `--text-label` / 控件正文 | 控件文本、按钮、表单标签、菜单项           |
| `--text-base` | 13   | `--text-body`             | 正文、列表主文本、表格单元（默认阅读字号） |
| `--text-md`   | 14   | 强调整文（见 §5）         | 状态栏实时读数、关键警示数字               |
| `--text-lg`   | 15   | `--text-subheading`       | 列表分组标题、表单分组标题                 |
| `--text-xl`   | 18   | `--text-title`            | 面板标题、分区标题                         |
| `--text-2xl`  | 21   | 顶栏主标题（见 §5）       | 仅用于顶栏主标题                           |
| `--text-3xl`  | 24   | `--text-display`          | 大屏关键 KPI 主数值                        |

规则：

- 不允许新增额外的 px 字号；如需补充，先在表中扩展一档并同步写明角色。
- 不允许在 SCSS / `<style>` 中直接写 `font-size: Xpx`，必须使用 `--text-*` 角色或 `--text-*` 档位令牌。
- `--text-base` 与 `--text-md`（13/14px）是给正文阅读保留的，控件、列表、表单行高都使用 `--text-sm`（12px）以保持大屏密度。
- `< 12px` 仅作 overline / caption 用途；任何承载主信息的文字必须 ≥ 12px（推荐 ≥ 13px），符合 WCAG 1.4.4 缩放原则。
- 同一行内字号差 ≤ 1 档；同一组件内字号差 ≤ 2 档；面板级对比允许 3 档（正文 vs 标题）。

## 4. 字体角色

仅保留两条字体栈，禁止在组件内声明自定义字体栈：

| 角色令牌           | 字体栈                                                                                                                           | 用途                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `--font-interface` | `Inter, "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif`                                                           | 所有中文与西文 UI 文案                   |
| `--font-mono`      | `"JetBrains Mono", "Fira Code", "SF Mono", "Cascadia Code", "Source Code Pro", Consolas, "Roboto Mono", ui-monospace, monospace` | 坐标、距离、角度、计数、时间戳、KPI 数值 |

组件语义别名：

```text
--font-display  := --font-interface
--font-title    := --font-interface
--font-body     := --font-interface
--font-label    := --font-interface
--font-mono     := --font-mono        /* 真实等宽栈 */
--font-data     := --font-mono        /* 历史别名，向后兼容 */
```

- 任何场景下，数字、坐标、距离、时长、计数必须使用 `--font-mono`（含 `.text-mono`），避免不同字符宽度造成表格抖动。
- 历史代码中的 `--font-data` 已重定向到 `--font-mono`，不再作为新增 API 使用。
- 中文场景下 `Inter` 缺失 glyph 时回退到 `HarmonyOS Sans SC` → `Microsoft YaHei` → `system-ui`，保证 Windows / macOS / 国产系统下视觉接近。

## 5. 字号角色（唯一权威映射）

组件写法优先使用以下 8 个角色类（已在 `global.css` 定义）：

| 角色类             | 字号         | 字重 | 行高 | 字距    | 适用场景                                                     |
| ------------------ | ------------ | ---- | ---- | ------- | ------------------------------------------------------------ |
| `.text-display`    | 24px         | 600  | 1.2  | -0.01em | 大屏关键指标大数字（如 KPI 主数值），`tabular-nums` 默认开启 |
| `.text-title`      | 18px         | 600  | 1.35 | 0       | `FloatingWindow` 标题、分区标题                              |
| `.text-subheading` | 15px         | 600  | 1.35 | 0       | 列表分组标题、表单分组标题                                   |
| `.text-body`       | 13px         | 400  | 1.5  | 0       | 普通正文、表格单元格、列表项主文本                           |
| `.text-label`      | 12px         | 500  | 1.35 | 0       | 控件文本、按钮文案、表单字段标签、Tab/菜单文字               |
| `.text-caption`    | 11px         | 400  | 1.35 | 0       | 次要说明、辅助提示、状态次要信息                             |
| `.text-overline`   | 10px         | 500  | 1    | 0.04em  | 全大写英文短标签                                             |
| `.text-mono`       | 与父元素一致 | —    | —    | —       | 仅设置 `font-feature-settings: "tnum"`，需配合其它角色类使用 |

特殊场景的字号使用规则：

- 顶栏主标题（如 `AppTopBar` 的项目名）：`--text-2xl`（21px） + 字重 600，行高 1.2，字距 -0.01em。
- 顶栏副标题：`--text-xl`（18px） + 字重 500，行高 1.35。
- 顶栏 / 状态栏的实时数据（FPS、时间、经纬度）：`--text-md`（14px） + `--font-mono`。
- 状态栏次要文字：`--text-sm`（12px）。
- 关键警示、错误提示中的数字：`--text-md`（14px） + `--font-mono` + 字重 600。
- 经纬度 / 海拔 / 比例尺等读数：`--text-xs`（11px） + `--font-mono`，便于在地图视口角落实时显示。

## 6. 字重

仅使用以下 4 档：

| 令牌                | 数值 | 用途                               |
| ------------------- | ---- | ---------------------------------- |
| `--weight-medium`   | 500  | 标签、按钮、次要强调               |
| `--weight-semibold` | 600  | 标题、强调字段、主 CTA、顶栏主标题 |
| `--weight-bold`     | 700  | KPI 数值、大数字、少数告警数字     |

规则：

- 不允许在组件中直接写 `font-weight: 600` 等数值，必须使用上述令牌。
- 早期 `--weight-strong` (650) 已合并到 `--weight-semibold` (600)；渲染上 600/650 在 Inter 上视觉差异极小，650 视为冗余档。
- 数字字重的选择：UI 文案 ≤ 600 以保持密度；KPI / 大数字使用 700 增强识别。
- 字重不是层级强化的唯一手段；字号、颜色、间距共同决定视觉层级，禁止用 700 代替颜色对比。

## 7. 行高与字距

仅使用以下 4 档行高：

| 令牌                | 数值 | 适用                           |
| ------------------- | ---- | ------------------------------ |
| `--leading-tight`   | 1.2  | 单行展示、大数字、徽章、状态点 |
| `--leading-snug`    | 1.35 | 标题、按钮、菜单、列表行       |
| `--leading-normal`  | 1.5  | 正文、表格、多行说明           |
| `--leading-relaxed` | 1.65 | 长说明（极少使用）             |

字距（letter-spacing）规则：

- 默认 0，不调整。
- 大字号（≥ 21px）收紧 `-0.01em`，避免西文在大字号下显得松散。
- 小字号 overline + 全大写时拉开 `0.04em`，补偿字符方头化造成的拥挤。
- 中文字符无需 letter-spacing 调整，保持默认 0。

## 8. 图标尺寸

字体图标（Bootstrap Icons 等）通过 `font-size` 控制可视尺寸，不属于正文系统。仅允许以下 5 档：

| 令牌        | 数值 | 场景                         |
| ----------- | ---- | ---------------------------- |
| `--icon-xs` | 12   | 工具栏小图标、列表前缀、徽章 |
| `--icon-sm` | 14   | 行内辅助图标                 |
| `--icon-md` | 16   | 标准图标按钮、加载 spinner   |
| `--icon-lg` | 20   | 主功能入口、KPI 行图标       |
| `--icon-xl` | 24   | 空状态、启动封面             |

规则：

- 图标尺寸同样不允许直接 `font-size: Xpx`，必须使用 `--icon-*` 令牌。
- 同一图标在 hover / pressed / disabled 状态下只允许改颜色或透明度，不允许改尺寸（避免布局抖动）。
- 与文字混排的图标使用与同字号文字的 `line-height` 对齐的图标尺寸（推荐 `--icon-sm` + 12/13/14 字号文本，`--icon-md` + 15/18 字号文本）。
- 仅颜色承载语义时（如状态点），必须额外提供文字或形状（图标字符本身就是形状），保证色盲可达性。

## 9. 数字与坐标

- 任何 K栏位、列表、表格、KPI 中的数字必须同时使用 `text-mono` 与对应的字号角色类。
- `tabular-nums` 已在 `.text-mono` 与 `.text-display` 上默认开启；新增 token 也应遵循。
- 整数与小数分隔统一使用 `toLocaleString`，禁止手动拼接千分位。
- 读数（如经纬度 `108.3271°`、距离 `12.4 km`）单位与数字之间保留一个半角空格。
- 数字溢出规则（与本规范配合的截断策略）：
  - 列表中允许截断并显示 `…`，悬停时通过 `title` 暴露完整数值。
  - 表格内不允许截断；列宽不足时优先换行（`overflow-wrap: anywhere`），禁止使用 `word-break: break-all`。

## 10. 暗色对比度

本项目主界面为暗色大屏，文案与面板背景的对比度必须满足：

| 用途                                       | 最低对比度            | 推荐对比度          |
| ------------------------------------------ | --------------------- | ------------------- |
| 正文 (`--text-primary` on `--surface-1/2`) | ≥ 4.5:1 (WCAG AA)     | ≥ 7:1 (AAA)         |
| 次要说明 (`--text-secondary`)              | ≥ 4.5:1               | ≥ 7:1               |
| 辅助提示 (`--text-muted`)                  | ≥ 3:1（大字号可放宽） | ≥ 4.5:1             |
| 图标、分割线、状态点                       | ≥ 3:1                 | ≥ 3:1               |
| 错误 / 告警 / 成功                         | ≥ 4.5:1 + 文字/图标   | ≥ 4.5:1 + 文字/图标 |

- 任何承载关键信息的字符（包括 `--text-muted`）不得单独使用，必须配合图标、字重或颜色对比。
- 新增 UI 颜色必须先在面板背景（`--surface-1` / `--surface-2` / `--surface-3`）上验证对比度，再写入 `src/styles/global.css`。

## 11. 字体加载与回退

- 仅在 `@theme` 中声明字体栈，不在组件层 import 任何字体文件。
- 系统字体回退顺序已包含在 `--font-interface` / `--font-mono`，允许浏览器自动选择最佳可用字体。
- 不强制下载远程字体，避免在弱网/离线大屏环境下 FOIT（不可见文本闪烁）；如需远程字体，必须配置 `font-display: swap` 与回退到 `--font-interface` 字体栈。
- 中英混排时无需分别设置 font-family；`Inter` 本身已含良好西文支持，中文自动回退到 `HarmonyOS Sans SC` / `Microsoft YaHei`。

## 12. 组件写法约定（Do / Don't）

### Do

```vue
<template>
  <!-- 面板标题 -->
  <header class="floating-title text-title">资源目录</header>

  <!-- 正文 + 等宽数字混排 -->
  <p class="text-body">
    最近一次更新：
    <span class="text-mono text-body">12 秒前</span>
  </p>

  <!-- 角注 -->
  <small class="text-caption">该字段影响图层加载顺序</small>

  <!-- 全大写英文短标签 -->
  <span class="text-overline">BETA</span>
</template>
```

### Don't

```vue
<template>
  <!-- ❌ 直接写 px 字号 -->
  <span style="font-size: 12px">…</span>

  <!-- ❌ 覆盖角色类的字重/行高 -->
  <span class="text-body" style="font-weight: 700; line-height: 1.4">…</span>

  <!-- ❌ 数字没开 tabular-nums 导致表格抖动 -->
  <td class="text-body">{{ count }} 条</td>

  <!-- ❌ 自定义字体栈 -->
  <style scoped>
    .custom {
      font-family: "PingFang SC", sans-serif;
    }
  </style>

  <!-- ❌ 把关键告警数字放在 9px 角标 -->
  <span class="badge" style="font-size: 9px">ERROR</span>
</template>
```

通用规则：

- 模板：直接使用角色类，不要在模板里写内联 `style="font-size: ..."`。
- 样式：使用角色类的元素不应再写 `font-size / font-weight / line-height`；需要变体时新增工具类（如 `.is-strong`）。
- 数字与坐标：在含数字的元素上同时加 `text-mono` 与对应角色类。
- 焦点环：所有交互元素必须可见聚焦环，颜色来自 `--cyan`，偏移 2px（密集控件 1px）。

## 13. 迁移对照表（速查）

迁移时一次性替换：

| 旧写法                               | 替换为                                                                                           |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `font-size: 8px`                     | 不允许；若为角标徽章，使用 `.text-overline`（10px）                                              |
| `font-size: 9px`                     | 不允许；若为徽章，使用 `.text-overline`                                                          |
| `font-size: 10px`                    | `var(--text-overline)` 或 `.text-overline`                                                       |
| `font-size: 11px`                    | `var(--text-caption)` 或 `.text-caption`                                                         |
| `font-size: 12px`                    | `var(--text-label)` 或 `.text-label`                                                             |
| `font-size: 13px`                    | `var(--text-body)` 或 `.text-body`                                                               |
| `font-size: 14px`                    | `var(--text-md)` + 角色类；强调整段建议用 `.text-body`（13px） + 字重 600                        |
| `font-size: 15px`                    | `var(--text-subheading)` 或 `.text-subheading`                                                   |
| `font-size: 17px`                    | 不允许；改用 `--text-subheading`（15px）或 `--text-title`（18px）                                |
| `font-size: 19px`                    | 不允许；改用 `--text-xl`（18px）或 `--text-display`（24px）                                      |
| `font-family: var(--font-data)`      | 保留（已指向 `--font-mono`），新增代码使用 `--font-mono`                                         |
| `font-weight: 500 / 600 / 650 / 700` | 对应 `--weight-medium / --weight-semibold / --weight-semibold / --weight-bold`（650 合并为 600） |

## 14. 违规清单

不允许再出现的写法：

- `font-size: 8px / 9px / 10px / 11px / 12px / 13px / 14px / 15px / 17px / 19px` 等直接 px（仅 `:root` 基础 16px 例外）。
- `font-family: <inline stack>`，必须使用 `--font-interface` / `--font-mono` / `--font-data`。
- `font-weight: 500 / 600 / 650 / 700` 等数值，必须使用 `--weight-*`。
- 在 SCSS / `<style>` 里覆盖 `.text-*` 角色类的字号、字重或行高。
- 把 ≥ 13px 的关键信息放在 `--text-muted` 上而不配合图标或字重。
- 表格 / 列表中的数字未开启 `tabular-nums`。
- 数字 / 链接 / 警告仅依赖颜色（不附文字 / 图标）。

## 15. 迁移顺序

1. 先收敛 `src/features/data/`、`src/features/layers/` 下管理端 / 资源 / 图层面板中的散乱 px（这一段散乱最多）。
2. 再收敛 `src/components/dashboard/` 下的功能面板与底/顶栏。
3. 最后处理 `src/components/` 顶层组件（`FloatingWindow`、`MapCompass`、`FlightTourPanel` 等）。
4. 每迁移一个组件，必须确保视觉无回归；表格、列表、坐标读数的字符宽度保持稳定。
5. 迁移完成后，按 §10 抽查暗色对比度；任何 < 4.5:1 的次要文字必须先调整颜色，再写回组件。
6. PR / 提交说明中标注「字体迁移」并列出影响文件清单，方便回归。
