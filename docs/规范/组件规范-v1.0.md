## 1. 目标与现状

### 1.1 目标

把当前大屏 UI 收敛为一套可复用、可审计的组件规范：

1. **统一圆角**：把 3/4/5/999px 等散乱硬编码收敛到 `--radius-xs/sm/md/lg/xl/pill` 6 档角色令牌。
2. **统一玻璃拟态层**：把 `backdrop-filter: blur(10/12/16px)` 三档合并为两档，按层级使用。
3. **统一边框与描边**：1px 浅光边、4 类对比强度的 `--panel-border-*` 角色。
4. **统一图标风格**：仅使用 Bootstrap Icons，单线 / 实心策略与语义绑定。
5. **统一反馈层级**：所有按钮、开关、列表项的 hover / pressed / focus / disabled / loading 状态必须按本规范。
6. **统一组件 API**：以 `FloatingWindow`、`MapCompass`、`LayerErrorToast` 为基准，按本规范迁移其它非标组件。

### 1.2 现状问题（基于 2026-09-12 静态扫描）

| 类别     | 现状                                                                 | 目标                                                                |
| -------- | -------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 圆角     | `border-radius: 3px / 4px / 5px / 999px` 等硬编码值散落 25+ 处       | 仅使用 `--radius-*` 6 档令牌                                        |
| 玻璃模糊 | `backdrop-filter: blur(10px / 12px / 16px)` 三档混用                 | 面板 16px、Toast 10px，统一两档                                     |
| 边框颜色 | 多处直接写 `rgba(72,229,255,0.45)`、`rgba(7,20,42,0.96)` 等          | 仅使用 `--panel-border-*` / `--panel-line-strong` 角色              |
| 阴影     | 仅 2 档（`--shadow-2/3`）但部分组件硬编码 `box-shadow: 0 0 0 2px` 等 | 统一到 `--shadow-1/2/3 + focus-ring` 5 类                           |
| 图标     | Bootstrap Icons 与少量 inline SVG 混用                               | 仅使用 Bootstrap Icons 类；需要图形自定义时用 SVG 并复用 `--icon-*` |
| 按钮尺寸 | `min-height: 24/30/32/36/44px` 多档                                  | 收敛到 `--control-xs/sm/md/lg/xl` 5 档                              |

## 2. 设计原则

| 原则             | 含义                                                                           | 反例                                         |
| ---------------- | ------------------------------------------------------------------------------ | -------------------------------------------- |
| **扁平优先**     | 同一层级的容器不堆叠多重阴影或渐变；视觉差异靠透明度和边框建立                 | 面板阴影 + 内嵌渐变 + 高斯模糊叠加           |
| **玻璃拟态聚焦** | 仅用于浮在地图/视频/3D 内容之上的浮层、面板、Toast；普通 UI 保持纯色背景       | 所有 `<button>`、所有 `<input>` 都加玻璃模糊 |
| **令牌唯一来源** | 所有数值、颜色、间距、圆角、模糊、字号必须来自 `global.css` 令牌               | 在 scoped SCSS 中复制 token 值               |
| **层级语义化**   | 容器层级（surface / panel / modal / toast / overlay）决定背景与模糊档位        | 任意层级都使用同一模糊强度                   |
| **状态可观测**   | 任何交互元素必须显式声明 hover / pressed / focus / disabled / loading 五态之一 | hover 才出现反馈、移除焦点环                 |
| **无障碍兜底**   | 颜色、模糊、阴影不可承载信息；状态必须配图标、文字或形状                       | 仅靠 `--cyan` 边框表示选中                   |
| **图标风格一致** | 全站只用一个图标集；同一图标在同一层级保持实心/线型一致                        | 在同一按钮里同时使用实心和线型图标           |

## 3. 圆角系统

仅保留以下 6 档，单位 `px`，写在 `global.css` 的 `@theme` 块：

| 令牌            | 数值 | 角色                               | 默认应用                    |
| --------------- | ---- | ---------------------------------- | --------------------------- |
| `--radius-xs`   | 3    | `--radius-input`                   | 输入框、行内 chip、紧凑标签 |
| `--radius-sm`   | 4    | `--radius-button`                  | 按钮、行内次要控件、列表项  |
| `--radius-md`   | 6    | `--radius-card` / `--radius-panel` | 普通卡片、面板、卡片列表    |
| `--radius-lg`   | 8    | `--radius-modal`                   | 模态弹窗、确认对话框        |
| `--radius-xl`   | 12   | —                                  | 大屏悬浮大面板、加载封面    |
| `--radius-pill` | 999  | `--radius-badge`                   | 徽章、状态点、开关轨道      |

规则：

- 任何 `border-radius: Xpx` 直接写法都必须改为对应 `--radius-*` 令牌；硬编码 `999px` 改用 `--radius-pill`。
- 同一组件内部层级最多使用 2 档圆角（例如：面板 `--radius-md`、面板内按钮 `--radius-sm`），超过 2 档视为过度装饰。
- 圆形头像、状态点用 `border-radius: 50%`，不视为圆角档位。

## 4. 间距系统

延续《字体与字号规范》中既有的 8 档间距（`--space-0…--space-10`），并定义复合间距角色：

| 令牌               | 数值 | 用途                     |
| ------------------ | ---- | ------------------------ |
| `--space-stack-xs` | 4    | 紧凑列表项间距           |
| `--space-stack-sm` | 8    | 列表项间距、表单字段间距 |
| `--space-stack-md` | 12   | 分组间距                 |
| `--space-stack-lg` | 16   | 分区间距                 |
| `--space-stack-xl` | 24   | 大区段间距               |

面板内边距档（按层级）：

| 角色令牌                 | 数值 | 用途                           |
| ------------------------ | ---- | ------------------------------ |
| `--space-panel-compact`  | 12   | 紧凑面板（工具条、过滤栏）     |
| `--space-panel-default`  | 14   | 普通面板（列表面板、详情面板） |
| `--space-panel-elevated` | 16   | 大屏主面板、模态弹窗           |

规则：

- 面板内任何内边距必须使用 `--space-panel-*`；不得直接 `padding: 12px`。
- 列表项内边距（左右）推荐 `--space-5`(10) 或 `--space-6`(12)，与列表项间距 `--space-stack-sm` 形成 1:1 的内/外比例。

## 5. 表面与阴影

### 5.1 表面档

`global.css` 中已定义 5 档表面，禁止新增：

| 令牌                | 数值 / 含义              | 用途                                 |
| ------------------- | ------------------------ | ------------------------------------ |
| `--surface-0`       | `#030913`                | 背景根色                             |
| `--surface-1`       | `rgba(7, 20, 42, 0.86)`  | 普通面板（实色）                     |
| `--surface-2`       | `rgba(10, 28, 56, 0.92)` | 浮起面板（实色）                     |
| `--surface-3`       | `rgba(3, 10, 24, 0.94)`  | 输入区（实色）                       |
| `--surface-toast`   | `rgba(24, 10, 20, 0.92)` | Toast 警告底色（语义色，独立 token） |
| `--surface-overlay` | `rgba(2, 7, 16, 0.72)`   | 模态遮罩                             |

复合角色别名（已存在）：

```text
--panel-bg          := --surface-1     /* 普通面板底色 */
--panel-bg-raised   := --surface-2     /* 浮起面板底色 */
--panel-bg-solid    := --surface-1     /* sticky 元素底色 */
--panel-input-bg    := --surface-3     /* 输入控件底色 */
```

### 5.2 阴影档

仅保留 3 档深度：

| 令牌         | 数值                  | 用途                                              |
| ------------ | --------------------- | ------------------------------------------------- |
| `--shadow-1` | `0 2px 6px ... 28%`   | 行内浮起元素（菜单、Tooltip）                     |
| `--shadow-2` | `0 16px 42px ... 52%` | 普通面板、浮窗（`--panel-shadow`）                |
| `--shadow-3` | `0 24px 64px ... 72%` | 模态弹窗、大屏主面板（`--panel-shadow-elevated`） |

辅助角色：

- `--ring`：焦点环（2px 实线 + `--cyan`）
- `--ring-offset`：焦点环偏移 2px
- `--ring-offset-tight`：小尺寸按钮焦点环偏移 1px

规则：

- 同一层级阴影最多使用 1 档，禁止叠加深阴影形成「双层阴影」。
- 玻璃面板仅在底色透明时叠加 `--shadow-2` 或 `--shadow-3`；不允许在阴影上再加 `inset` 阴影。
- 自定义发光效果（如选中项的发光描边）必须基于 `--ring` 体系，禁止引入 `--cyan/--amber/--rose` 之外的霓虹色。

## 6. 玻璃拟态层

仅在浮于地图之上的 3 类容器使用玻璃效果，按层级使用统一模糊档：

| 层级     | 模糊强度            | 背景透明度              | 边框                                   | 应用                                     |
| -------- | ------------------- | ----------------------- | -------------------------------------- | ---------------------------------------- |
| 普通浮层 | `--blur-panel` 16px | `rgba(7, 20, 42, 0.62)` | `1px solid var(--panel-border-soft)`   | `FloatingWindow`、二级菜单、详情面板     |
| 模态浮层 | `--blur-panel` 16px | `rgba(7, 20, 42, 0.78)` | `1px solid var(--panel-border)`        | `ConfirmationModal`、大屏主弹窗          |
| Toast    | `--blur-toast` 10px | `rgba(7, 20, 42, 0.92)` | `1px solid var(--cyan/rose/amber 45%)` | `ActionFeedbackToast`、`LayerErrorToast` |

新增令牌（在 `global.css` 的 `@theme` 块补齐）：

```text
--blur-panel: 16px
--blur-toast: 10px
--glass-bg:        color-mix(in srgb, var(--surface-1) 78%, transparent)
--glass-bg-raised: color-mix(in srgb, var(--surface-2) 86%, transparent)
--glass-bg-toast:  color-mix(in srgb, var(--surface-3) 92%, transparent)
```

规则：

- `backdrop-filter` 必须引用 `--blur-panel` 或 `--blur-toast`，禁止直接 `blur(10px)`。
- 普通按钮、输入框、行内 chip 不使用玻璃模糊，避免性能开销与视觉杂乱。
- `backdrop-filter` 必须同时写 `-webkit-backdrop-filter` 以兼容 Safari。
- 玻璃面板内部不再叠加独立阴影，只保留 `--shadow-2/3`。

## 7. 边框

边框档（按对比强度递增）：

| 令牌                    | 用途                     |
| ----------------------- | ------------------------ |
| `--panel-border-inner`  | 面板内分组、虚分隔       |
| `--panel-border-soft`   | 普通浮层玻璃边框         |
| `--panel-border`        | 模态边框、强调容器       |
| `--panel-border-strong` | 输入框、按钮、聚焦态边框 |
| `--panel-line-strong`   | 列表项、表格行分隔       |

规则：

- 任何 `border: 1px solid <任意颜色>` 必须改为对应 `--panel-*` 角色。
- 边框宽度仅保留 `1px`，不允许 2px 实线边框；强调态通过颜色（`--panel-border-strong`）实现。
- 玻璃面板的「发光描边」效果禁止使用 `box-shadow: 0 0 0 2px <cyan>` 等大范围阴影；用 `outline: 1px solid --cyan` + `--ring-offset` 替代。

## 8. 图标

### 8.1 图标集

- 仅使用 **Bootstrap Icons**（仓库内已存在），按语义选用。
- 自定义图形使用 inline SVG，并通过 `currentColor` 继承父元素文字色。

### 8.2 图标尺寸

延续《字体与字号规范》中的 5 档：

| 令牌        | 数值 | 场景                   |
| ----------- | ---- | ---------------------- |
| `--icon-xs` | 12   | 行内角标、列表前缀     |
| `--icon-sm` | 14   | 行内辅助、按钮内图标   |
| `--icon-md` | 16   | 标准按钮、加载 spinner |
| `--icon-lg` | 20   | 主功能入口、KPI 行图标 |
| `--icon-xl` | 24   | 空状态、启动封面       |

### 8.3 实心 vs 线型

| 层级                 | 风格                | 示例                 |
| -------------------- | ------------------- | -------------------- |
| 工具栏、二级菜单入口 | 线型（`bi-*`）      | `bi-arrow-clockwise` |
| 选中态、激活态       | 实心（`bi-*`-fill） | `bi-bookmark-fill`   |
| 状态点、徽章         | 实心                | `bi-circle-fill`     |
| 表单内交互图标       | 线型                | `bi-search`          |

规则：

- 同一按钮内 hover 前/后必须保持同风格（线型→线型、实心→实心），仅切换颜色与透明度。
- 图标不可独立承载状态含义，必须配合文字、徽章或边框；色盲用户才能感知。

## 9. 按钮

### 9.1 尺寸

| 令牌           | 高度 | 命中区 | 典型场景                   |
| -------------- | ---- | ------ | -------------------------- |
| `--control-xs` | 24   | 32     | 行内 chip、紧凑列表操作    |
| `--control-sm` | 32   | 40     | 工具栏、过滤栏             |
| `--control-md` | 36   | 44     | 默认按钮、面板底部操作     |
| `--control-lg` | 44   | 52     | 模态弹窗主按钮             |
| `--control-xl` | 56   | 64     | 大屏启动封面、空状态主操作 |

`--hit-min: 32px`、`--hit-recommended: 36px`、`--hit-touch: 44px` 三档命中区沿用。

### 9.2 变体

仅允许 5 类语义变体（与既有 `global.css` 中的 `.btn-*` 一致）：

| 变体类           | 边框                    | 背景                    | 文字                    | 适用                        |
| ---------------- | ----------------------- | ----------------------- | ----------------------- | --------------------------- |
| `.btn-primary`   | `--cyan` 60% 透明       | `--blue` 36%            | `--cyan`                | 主 CTA、表单提交、确认操作  |
| `.btn-secondary` | `--panel-border-soft`   | `--surface-2`           | `--text-primary`        | 次要操作、列表项操作        |
| `.btn-ghost`     | transparent             | transparent             | `--text-secondary`      | 工具栏、低权重操作          |
| `.btn-danger`    | `--rose-soft` 70%       | `--rose-bg`             | `--rose`                | 删除、停止、解绑等危险操作  |
| `.btn-compact`   | （同 `.btn-secondary`） | （同 `.btn-secondary`） | （同 `.btn-secondary`） | 仅修饰尺寸至 `--control-sm` |

规则：

- 同一操作组最多 1 个 `.btn-primary`，其它按钮使用 `.btn-secondary` 或 `.btn-ghost`；危险操作必须使用 `.btn-danger` 并二次确认。
- 按钮文字使用 `.text-label`（12px） + `--weight-semibold`（600）。
- 按钮左右内边距至少 `--space-5`(10)；图标与文字间距 `--space-3`(6)。
- 加载中的按钮：图标位替换为 `--icon-sm` spinner；按钮文字保持不变；按钮 `aria-busy="true"` 且 `disabled`。

### 9.3 状态机

| 状态     | 视觉反馈                                                   | 是否禁用交互       |
| -------- | ---------------------------------------------------------- | ------------------ |
| 默认     | 主色边框 + 主色背景 + 主色文字                             | 否                 |
| hover    | 边框与背景透明度 +10%；cursor pointer                      | 否                 |
| pressed  | `transform: scale(0.97)` + `opacity: 0.85`（已有全局规则） | 否                 |
| focus    | `outline: var(--ring)` + `--ring-offset`                   | 否                 |
| disabled | `opacity: 0.5` + `cursor: not-allowed`                     | 是                 |
| loading  | spinner + 文字保持 + `aria-busy="true"`                    | 是（不再触发点击） |

### 10.2 普通卡片 / 列表项

- 圆角：`--radius-card` (md) 或 `--radius-button` (sm)

- 边框：`--panel-line-strong`

### 10.3 大屏主面板

- 圆角：`--radius-xl` (12)
- 背景：`--glass-bg-raised`
- 边框：`--panel-border`
- 模糊：`--blur-panel`
- 阴影：`--panel-shadow-elevated`

### 10.4 状态

| 状态                | 反馈                                                            |
| ------------------- | --------------------------------------------------------------- |
| 默认                | 上述基础样式                                                    |
| hover（仅列表项）   | 背景 → `--row-hover-bg`；圆角不变                               |
| 选中（列表项 / 行） | 左侧 3px `--cyan` 实线 + 背景 → `--row-active-bg`（已有 token） |
| 拖拽中              | `--shadow-2` + 边框 `--panel-border-strong`                     |

## 11. 表单字段

### 11.1 输入框 / 下拉 / 文本域

- 圆角：`--radius-input` (xs)
- 高度：默认 `--control-md` (36)，密集列表内 `--control-sm` (32)
- 内边距：`--space-4`(8) 横向 + `0` 纵向
- 背景：`--panel-input-bg` (即 `--surface-3`)
- 边框：`--panel-line-strong`
- 文字：`--text-body` (13) + `--text-primary`
- 占位符：`--text-muted`
- 命中区与高度对齐，`min-width: 0` 必须设置以允许在 flex/grid 内收缩

### 11.2 状态

| 状态     | 反馈                                                              |
| -------- | ----------------------------------------------------------------- |
| 默认     | 上述基础样式                                                      |
| hover    | 边框 → `--panel-border`                                           |
| focus    | 边框 → `--cyan` + `outline: var(--ring)` + `--ring-offset`        |
| disabled | `opacity: 0.5` + `cursor: not-allowed`                            |
| error    | 边框 → `--rose-soft`，下方显示错误信息（关联 `aria-describedby`） |
| readonly | 边框保持 `--panel-line-strong`，文字色 `--text-secondary`         |

### 11.3 校验

- 校验时机：在 `blur` 时校验；不在 `input` 期间打断用户。
- 错误展示：错误信息紧贴字段下方（`--text-caption` + `--rose`），并 `aria-describedby` 关联。
- 错误摘要：表单提交失败时，顶部插入可聚焦的错误摘要（链接到第一个错误字段）。

### 11.4 标签与帮助文字

- 字段标签：`--text-label` (12) + `--text-secondary`，使用 `<label for>` 显式关联。
- 帮助文字：`--text-caption` (11) + `--text-muted`，紧贴字段下方或字段内右侧。
- 必填指示：标签后跟 `*` + `--rose`，或字段前缀小图标 `bi-asterisk`。

## 12. 列表与表格

### 12.1 列表项

- 高度：默认 `--control-md` (36)，密集 `--control-sm` (32)，强调行 `--control-lg` (44)
- 内边距：`--space-5`(10) 横向 + 0 纵向
- 间距：`--space-stack-sm` (8) 列表项之间
- 圆角：`--radius-button` (sm)；选中状态由左侧 3px 实线指示，不依赖整行变色

### 12.2 表格

- 表头：`--text-overline` (10) + 大写 + `--text-muted`；高度 `--control-md` (36)
- 单元：`--text-body` (13)；内边距 `--space-4`(8) + `--space-5`(10)
- 行高：`--leading-snug` (1.35)
- 行分隔：`1px solid --panel-inner-line`
- 选中行：背景 `--row-active-bg` + 左侧 3px `--cyan` 实线
- 数字列：使用 `text-mono text-body`；右对齐
- 排序：表头可点击排序，aria-sort 同步当前状态

### 12.3 空状态

- 居中布局；图标 `--icon-xl` (24) + `--text-muted`
- 标题：`--text-subheading` (15) + `--text-primary`
- 说明：`--text-caption` (11) + `--text-secondary`
- 主操作按钮：`.btn-primary` + `--control-lg`

## 13. 模态 / 弹窗 / 抽屉

### 13.1 模态弹窗

- 圆角：`--radius-modal` (lg)
- 背景：`--glass-bg-raised`
- 边框：`--panel-border`
- 模糊：`--blur-panel`
- 阴影：`--panel-shadow-elevated`
- 内边距：`--space-panel-elevated` (16)
- 标题：`--text-title` (18) + `--weight-semibold`
- 关闭按钮：右上角 32×32 命中区
- 底部操作区：主按钮 `.btn-primary` + 次按钮 `.btn-secondary`，右对齐，间距 `--space-stack-sm`

### 13.2 确认对话框

- 标题使用祈使句；正文使用陈述句并明确后果
- 危险操作主按钮使用 `.btn-danger`；普通操作使用 `.btn-primary`
- 必须提供「取消」出口，按 `Esc` 等同取消

### 13.3 抽屉 / 侧栏

- 圆角：靠地图侧 0，靠外侧 `--radius-md`
- 宽度：固定档（320 / 360 / 420 / 480）；禁止固定像素以外的容器宽度
- 滚动：仅内部滚动（`overflow: auto`），禁止与主视口滚动嵌套

### 13.4 遮罩

- 颜色：`--surface-overlay`
- 模糊：可选 `--blur-panel`；当背景为地图时强烈建议叠加
- 点击遮罩：非危险操作允许关闭；危险操作禁止点击关闭

## 14. Toast / 通知

### 14.1 视觉

- 圆角：`--radius-button` (sm)
- 背景：`--glass-bg-toast`
- 边框：按类型选色（cyan / rose / amber）
- 模糊：`--blur-toast`
- 阴影：`--panel-shadow-elevated`
- 内边距：`--space-5`(10) + `--space-6`(12)
- 文字：`--text-label` (12)
- 容器最大宽：`--space-panel-elevated` × 20 = 320px 附近

### 14.2 行为

- 自动消失：3–5 秒（信息类）；错误类不自动消失，提供「关闭」按钮。
- 焦点：Toast 不抢焦点；使用 `aria-live="polite"`（信息）或 `role="alert"`（错误）。
- 位置：右上角；多个 Toast 纵向堆叠，间距 `--space-stack-sm`。
- 操作：允许内嵌一个 `.btn-ghost` 「撤销」「重试」按钮。

## 15. Tooltip

- 圆角：`--radius-xs` (3)
- 背景：`--surface-2` 实色（不使用玻璃）
- 边框：1px `--panel-border`
- 阴影：`--shadow-1`
- 内边距：`--space-3`(6) + `--space-4`(8)
- 文字：`--text-caption` (11) + `--text-primary`
- 箭头：4px 三角形，颜色与背景同
- 触发：hover 250ms 延迟 / focus 立即；离开 100ms 延迟后消失；可键盘 `Esc` 关闭

## 16. 加载与状态

### 16.1 Skeleton

- 形状：圆角与目标元素一致
- 颜色：底色 `--surface-2`；上层 `linear-gradient` 使用 `color-mix(in srgb, var(--blue) 18%, transparent)`
- 动效：1.4s 线性渐变平移；`prefers-reduced-motion` 下禁用

### 16.2 Spinner

- 尺寸：`--icon-sm`(14) / `--icon-md`(16) / `--icon-lg`(20)
- 颜色：`--cyan`
- 动效：1s 线性旋转；`prefers-reduced-motion` 下静态

### 16.3 Progress

- 高度：`--control-xs` (24) 内进度条 `--space-1` (2)
- 轨道：`--surface-3`；填充 `--cyan`
- 必须配文字标签（百分比 / 剩余时间）

### 16.4 错误态

- 整页错误：使用 `ErrorBoundary.vue` 占位 + 标题 + 描述 + 重试按钮
- 行内错误：在对应行/单元格展示 `--rose` 图标 + 简短说明 + 「详情」入口
- 网络错误：明确告知原因（超时 / 离线 / 服务不可达）+ 修复建议

## 17. 反馈与交互

### 17.1 5 态映射

所有交互元素（按钮、开关、列表项、卡片、菜单项）必须显式声明 5 态之一：

| 状态     | 视觉                                   | 是否可交互 | 是否可聚焦     |
| -------- | -------------------------------------- | ---------- | -------------- |
| default  | 基础样式                               | 是         | 是             |
| hover    | 边框 / 背景透明度 +10%                 | 是         | 是             |
| pressed  | `scale(0.97)` + `opacity: 0.85`        | 是         | 是             |
| focus    | `outline: var(--ring)`                 | 是         | 是（默认即此） |
| disabled | `opacity: 0.5` + `cursor: not-allowed` | 否         | 否             |

### 17.2 切换器（开关 / 单选 / Tab）

- 开关使用 `role="switch"` + `aria-checked`；按下用边框颜色变化（不允许动画形变）。
- 单选用 `role="radio"` + `aria-checked`，或 `radiogroup` 容器。
- Tab 用 `role="tab"` + `aria-selected`，键盘左右切换。

### 17.3 反馈时机

- 操作即时反馈（< 100ms）：按钮 pressed、开关切换
- 操作完成反馈（< 300ms）：列表插入、Toast 出现
- 异步操作反馈（> 300ms）：必须显示 spinner 或骨架；不允许空白等待

## 18. 动效

仅使用 `global.css` 中既有的动效令牌：

| 令牌                       | 数值                                | 用途                      |
| -------------------------- | ----------------------------------- | ------------------------- |
| `--motion-duration-fast`   | 100ms                               | pressed、checkbox 切换    |
| `--motion-duration-base`   | 180ms                               | hover、边框变色、背景变色 |
| `--motion-duration-medium` | 240ms                               | 开关、面板展开            |
| `--motion-duration-slow`   | 320ms                               | 模态进入、抽屉滑入        |
| `--motion-ease-standard`   | `cubic-bezier(0.2, 0, 0, 1)`        | 默认                      |
| `--motion-ease-emphasized` | `cubic-bezier(0.32, 0.72, 0.25, 1)` | 开关、强调过渡            |

规则：

- 进入动效比离开动效长 30–50%（exit-faster-than-enter），离开推荐 180ms / 进入 240ms。
- 仅动画 `transform` 与 `opacity`，禁止动画 `width / height / top / left` 触发回流。
- `prefers-reduced-motion: reduce` 必须把所有动画压到 0.001ms（`global.css` 已实现，全局生效）。

| 令牌           | 数值 | 用途                     |

| `--z-base`     | 0    | 地图 / 3D 视口           |
| `--z-content`  | 10   | 地图覆盖物（draw、测量） |
| `--z-status`   | 20   | 顶栏 / 底栏              |

## 20. 命名与文件结构

### 20.1 文件命名

- 通用组件放 `src/components/`，PascalCase，如 `FloatingWindow.vue`、`MapCompass.vue`。
- 大屏专用组件放 `src/components/dashboard/`，按模块命名，如 `DrawingPanel.vue`、`MeasurementPanel.vue`。
- 业务功能组件按域放 `src/features/<domain>/`，如 `src/features/data/LayerEditor.vue`。
- 跨域复用基础组件（按钮、表单字段）未来考虑提取到 `src/components/base/`，目前复用 `global.css` 中的工具类。

### 20.2 类命名约定

- 工具类以 `is-` / `has-` 前缀表示状态：`is-active`、`is-disabled`、`has-error`。
- 变体类以 `btn-` / `panel-` 等组件前缀：`btn-primary`、`panel-elevated`。
- 角色类（来自《字体与字号规范》）使用 `text-*` 前缀：`text-body`、`text-label`。

### 20.3 Props 约定

- `disabled` / `loading` / `error` 必须三选一或并存，使用 `aria-*` 对应暴露。
- 标题用 `title` prop；描述用 `description`；避免使用 `label` 作为标题。
- 关闭回调统一 `onClose`；异步操作结果统一 `onComplete` / `onError`。

## 22. Do / Don't 示例

### Do

```vue
<template>
  <!-- 浮窗面板 -->
  <FloatingWindow :title="title" @close="onClose">
    <p class="text-body">{{ description }}</p>
  </FloatingWindow>

  <!-- 主按钮 -->
  <button type="button" class="btn-primary" :disabled="loading" :aria-busy="loading">
    {{ loading ? "提交中…" : "提交" }}
  </button>
</template>
```

### Don't

```vue
<template>
  <!-- ❌ 硬编码圆角 + 模糊 -->
  <div class="panel" style="border-radius: 5px; backdrop-filter: blur(10px);">…</div>

  <!-- ❌ 多个 primary 按钮 -->
  <button class="btn-primary">保存</button>
  <button class="btn-primary">提交</button>

  <!-- ❌ 危险操作无确认 -->
  <button class="btn-secondary" @click="removeLayer">删除图层</button>

  <!-- ❌ 按钮缺少 hover/focus 反馈 -->
  <button style="background: cyan;">操作</button>
</template>
```

## 23. 违规清单

不允许再出现的写法：

- `border-radius: <Xpx>` 直接值，必须使用 `--radius-*`。
- `border: 1px solid <任意颜色>`，必须使用 `--panel-*` 角色。
- `backdrop-filter: blur(<Xpx>)` 直接值，必须使用 `--blur-panel` / `--blur-toast`。
- `min-height: <Xpx>`（控件），必须使用 `--control-*`。
- 同一组件内圆角档位超过 2 档。
- 普通按钮 / 输入框使用玻璃模糊。
- 模态弹窗不带 `Esc` 关闭、不带遮罩点击规则说明。
- 表单错误仅在提交时显示，不在字段下方就近展示。
- 操作反馈仅靠颜色（无文字 / 无图标）。
- 在按下时改变布局（`transform: scale` 除外）。
- 自定义图标字体或 emoji 充当结构化图标。

## 24. 迁移顺序

1. 先把 `global.css` 补齐本规范新增的令牌（`--blur-panel / --blur-toast / --glass-bg* / --z-*` 等）。
2. 按 §21 第一批清单迁移数据管理 / 资源 / 图层相关面板；优先收敛 `border-radius` 与 `border` 直接值。
3. 按 §21 第二批迁移大屏操作面板；优先统一 `backdrop-filter` 与 `min-height`。
4. 抽样验证：随机抽取 5 个组件，校验圆角、边框、阴影、模糊、按钮尺寸全部走令牌。
5. 在 CI / lint 中加入 stylelint 规则（后续任务），禁止散乱写法再次出现。
6. PR 说明标注「组件迁移」并列出影响文件清单。
